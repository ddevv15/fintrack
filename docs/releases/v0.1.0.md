## FinTrack v0.1.0 — Release 1

FinTrack's first public release is a complete, usable slice of personal spend
tracking: log everyday purchases, review the current month, and see exactly
which categories took the most.

### Highlights

- Private accounts with email/password and Google sign-in
- Personal currency and timezone settings
- Fast spend entry with category, date, and an optional note
- Exact monthly totals and a newest-first transaction ledger
- Edit and delete flows for correcting mistakes
- Ranked category breakdowns with percentages that add up to 100%
- Responsive, keyboard-friendly UI with light and dark modes
- Postgres row level security for every table containing personal data
